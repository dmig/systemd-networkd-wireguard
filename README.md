# systemd-networkd-wireguard

`systemd-networkd` Wireguard configurator

## Use cases

1. Server confifguration
   1. [v] Create server keys
   2. [v] Set network subnets
   3. [v] set listen port
   4. [v] set interface name and description
2. Peer actions
   1. [ ] create peer
   2. [ ] set allowedips
   3. [ ] delete peer
   4. [ ] export peer config
